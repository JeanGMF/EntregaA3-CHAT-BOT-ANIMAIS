# Chatbot de Zoologia com Aprendizado de Máquina (TF-IDF)

## Descrição
Este projeto implementa um chatbot capaz de responder perguntas sobre animais utilizando técnicas de Processamento de Linguagem Natural (NLP). O sistema utiliza vetorização TF-IDF e Similaridade de Cosseno para encontrar a melhor resposta e possui um módulo de aprendizado contínuo.

## Requisitos do Sistema
- Python 3.8 ou superior
- Bibliotecas listadas em requirements.txt

## Instalação e Execução

1. Abra o terminal na pasta 'código fonte'.
2. Instale as dependências com o comando:
   pip install -r requirements.txt

3. Execute o chatbot:
   python chatbot_animais.py

## Como Usar
- O chatbot iniciará no terminal.
- Digite sua pergunta em linguagem natural (ex: "Onde vive o leão?").
- Se o bot não souber a resposta (confiança < 40%), ele pedirá para você ensinar a resposta correta.
- Digite "sair" para encerrar.

## Estrutura de Arquivos
- chatbot_animais.py: Código principal e lógica da IA.
- base_conhecimento.txt: Banco de dados textual (pergunta|resposta).
- requirements.txt: Lista de bibliotecas necessárias.
